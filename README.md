# RadicalMart: AJAX-поиск товаров (mod_radicalmart_search)

Модуль Joomla 5/6 для интернет-магазина на [RadicalMart](https://radicalmart.ru/): строка поиска с живыми подсказками. Пока посетитель печатает, под полем появляется список товаров с картинкой, названием, артикулом и ценой; по Enter или кнопке он попадает на страницу каталога с результатами.

> Модуль сторонний и не является частью RadicalMart. Он использует штатные модель и маршруты компонента `com_radicalmart`, но разработан отдельно.

## Возможности

- подсказки без перезагрузки страницы (AJAX через стандартный `com_ajax` Joomla);
- в подсказке: картинка, название (до двух строк), артикул, цена;
- поиск по **артикулу** (без учёта регистра, пробелов и дефисов: `PL359`, `pl-359` и `PL 359` найдут одно и то же) и по **названию** товара;
- точные совпадения показываются первыми;
- цена берётся строкой из RadicalMart, поэтому поддерживаются валюта и тексты вроде «Цена по запросу» из ценовых плагинов;
- задержка перед запросом (debounce), чтобы не слать запрос на каждую букву;
- закрытие списка кликом вне поля, повторный показ при возврате фокуса;
- по Enter или кнопке: если запрос точно совпал с артикулом, переход сразу на страницу товара, иначе на каталог с результатами;
- устаревший запрос отменяется, когда посетитель продолжает печатать, на экране остаётся ответ на последний ввод;
- несколько экземпляров модуля на одной странице;
- языки: русский и английский;
- работает с шаблонным переопределением (`html/mod_radicalmart_search/default.php`).

## Требования

| Что | Примечание |
|---|---|
| Joomla | 5 или 6 |
| RadicalMart | 3-й версии: компонент `com_radicalmart`, его таблица товаров `#__radicalmart_products` и модель `Products` (сайт) |
| Bootstrap 5 в шаблоне | в разметке используются классы `input-group`, `form-control`, `btn btn-primary` |
| JavaScript в браузере | без него остаётся обычное поле без подсказок |

## Установка

1. Скачайте `mod_radicalmart_search_<версия>.zip` из раздела [Releases](../../releases).
2. «Система → Установка → Расширения» → загрузить архив.
3. «Содержимое → Модули сайта → Создать» → «RadicalMart - Поиск товаров».
4. Выберите позицию, назначьте на нужные страницы, опубликуйте.
5. По желанию укажите в «Пункте меню каталога» страницу, на которую ведёт кнопка поиска.

## Как это работает

1. Посетитель вводит текст. Если длина не меньше «Минимум символов», то после паузы («Задержка») браузер отправляет запрос:

   ```text
   <корень сайта>/index.php?option=com_ajax&module=radicalmart_search&method=get&format=json&limit=<N>&query=<текст>
   ```

   `limit` берётся из настройки «Максимум результатов» (допустимо 1–50, по умолчанию 10).
2. Joomla через `com_ajax` вызывает `RadicalMartSearchHelper::getAjax()`. Он делает два быстрых запроса к опубликованным товарам (`state = 1`):
   - по **артикулу**: код приводится к верхнему регистру без пробелов и дефисов, совпадение по вхождению, точное совпадение первым;
   - по **названию**: слова запроса должны встречаться в названии **в том же порядке**, точное совпадение первым.
3. Найденные идентификаторы загружаются штатной моделью RadicalMart `Products`, поэтому цена, ссылка и картинка готовятся ровно так же, как в каталоге (включая сторонние ценовые плагины).
4. Сначала идут товары, найденные по артикулу, затем по названию, повторы убираются, список обрезается до `limit`.
5. Ответ приходит в виде JSON, скрипт рисует список. Клик по подсказке ведёт на страницу товара.

Поиск идёт **только по артикулу и названию**: описания и характеристики не учитываются. Это сделано намеренно, иначе по запросу «бетон» подсказывалась спецтехника, в описании которой встретилось это слово.

Формат ответа:

```json
{
  "success": true,
  "items": [
    {
      "id": 12,
      "title": "Название товара",
      "link": "https://example.com/catalog/product-12",
      "image": "https://example.com/images/p12.jpg",
      "price": "1990",
      "price_string": "1 990 ₽",
      "code": "PL-359",
      "code_exact": false,
      "in_stock": true
    }
  ],
  "total": 1
}
```

`code_exact` равен `true`, если артикул совпал с запросом полностью. Если запрос короче двух символов или произошла ошибка, приходит `{"success": false, "items": [], "message": "..."}`. Подробности ошибки записываются в журнал Joomla (файл `mod_radicalmart_search.php` в папке логов), посетителю они не показываются.

### Кнопка и Enter

По кнопке «Найти» или Enter модуль ещё раз спрашивает сервер и смотрит на поле `code_exact`:

- если артикул совпал с запросом **полностью** (регистр, пробелы и дефисы не важны), посетитель сразу попадает на страницу этого товара;
- иначе происходит переход на страницу каталога со штатным параметром поиска RadicalMart:

```text
<адрес каталога>?filter[search]=<запрос>
```

Если запрос завершился ошибкой, тоже происходит переход на каталог. Адрес каталога берётся из настройки «Пункт меню каталога»; если пункт не выбран, ведёт на корневую категорию RadicalMart.

## Настройки модуля

| Параметр | По умолчанию | Назначение |
|---|---|---|
| Текст кнопки | Найти | подпись кнопки |
| Placeholder | Поиск товаров... | подсказка в поле |
| Минимум символов | 2 | с какой длины запроса начинать поиск (1–10) |
| Максимум результатов | 10 | сколько подсказок показывать (1–50) |
| Задержка (мс) | 300 | пауза после последней буквы перед запросом (100–2000) |
| Пункт меню каталога | не выбран | куда вести кнопку и Enter |
| Макет | default | стандартный выбор макета, можно подключить свой |
| Суффикс CSS-класса | пусто | добавляется к обёртке `.radicalmart-search-wrapper` |
| Кэширование | выключено | вывод зависит от запроса, кэшировать модуль не нужно |

## Стили и переопределение вёрстки

Стили записаны прямо в `tmpl/default.php`. Основные классы:

| Класс | Что это |
|---|---|
| `.radicalmart-search-wrapper` | обёртка модуля |
| `.search-autocomplete-results` | выпадающий список (`.show` показывает его) |
| `.search-autocomplete-item` | одна подсказка (ссылка) |
| `.search-autocomplete-item-title`, `.search-autocomplete-item-code`, `.search-autocomplete-item-price` | название, артикул, цена |
| `.search-autocomplete-loading`, `.search-autocomplete-no-results` | «Поиск...» и «Ничего не найдено» |

Чтобы изменить вид или разметку, скопируйте `tmpl/default.php` в `templates/<шаблон>/html/mod_radicalmart_search/default.php` и правьте копию. Стили можно переопределять и обычным CSS шаблона.

Тексты скрипта («Поиск...», «Ничего не найдено», «Ошибка при поиске», «Арт.») лежат в языковых файлах `language/*/mod_radicalmart_search.ini`.

## Безопасность

- Всё, что приходит в подсказку (название, артикул, цена, ссылка, картинка), экранируется перед вставкой в страницу; ссылки и картинки принимаются только с `http(s)://` или от корня сайта (`javascript:`, `data:` и `//host` отбрасываются).
- Запросы к базе используют привязку параметров; символы `%` и `_` в запросе посетителя ищутся буквально.
- Текст внутренних ошибок не отдаётся в браузер, только в журнал.
- Адрес запроса и тексты вставляются в страницу кодированным JSON (`JSON_HEX_*`), поэтому не могут «закрыть» тег `<script>`.

## Ограничения

- Ограничения частоты запросов нет, есть только задержка в браузере. При большом трафике стоит ограничить `com_ajax` на уровне веб-сервера.
- Если у ценовых плагинов нет строки цены (`price_string`), к числу добавляется «₽».
- Поиск идёт напрямую по таблице `#__radicalmart_products` (поля `id`, `title`, `code`, `state`). Если структура RadicalMart изменится, нужно обновить запросы в `RadicalMartSearchHelper`.
- Стили и скрипт выводятся прямо в странице для каждого экземпляра модуля.

## Структура

```text
mod_radicalmart_search.xml          манифест
mod_radicalmart_search.php          точка входа, подключает макет
helper.php                          класс ModRadicalmartSearchHelper для com_ajax (вызывает getAjax)
services/provider.php               DI Joomla
src/Dispatcher/Dispatcher.php       данные для макета: адрес каталога, язык RadicalMart
src/Helper/RadicalMartSearchHelper.php   AJAX-поиск по артикулу и названию
tmpl/default.php                    разметка, стили и скрипт подсказок
language/ru-RU, language/en-GB      языковые файлы
tools/build.sh                      сборка установочного архива
```

Пространство имён: `Joomla\Module\RadicalMartSearch`.

## Сборка из исходников

```bash
tools/build.sh
```

Архив появится в `dist/`. Пути внутри него записываются через `/` (скрипт сам это проверяет).
