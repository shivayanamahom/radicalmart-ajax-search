# RadicalMart: AJAX-поиск товаров (mod_radicalmart_search)

Модуль Joomla 5/6 для интернет-магазина на [RadicalMart](https://radicalmart.ru/): строка поиска с живыми подсказками. Пока посетитель печатает, под полем появляется список товаров с картинкой, названием и ценой; по Enter или кнопке он попадает на страницу каталога с результатами.

> Модуль сторонний и не является частью RadicalMart. Он использует штатные модель и маршруты компонента `com_radicalmart`, но разработан отдельно.

## Возможности

- подсказки без перезагрузки страницы (AJAX через стандартный `com_ajax` Joomla);
- в подсказке: картинка товара, название (до двух строк), цена;
- поиск по названию (учитываются все слова запроса) и по артикулу;
- задержка перед запросом (debounce), чтобы не слать запрос на каждую букву;
- закрытие списка кликом вне поля, повторный показ при возврате фокуса;
- переход на каталог по Enter или кнопке;
- несколько экземпляров модуля на одной странице (у каждого свои идентификаторы);
- работает с шаблонным переопределением (`html/mod_radicalmart_search/default.php`).

## Требования

| Что | Примечание |
|---|---|
| Joomla | 5 или 6 |
| RadicalMart | 3-й версии: нужен компонент `com_radicalmart` и его модель `Products` (сайт) |
| Bootstrap 5 в шаблоне | в разметке используются классы `input-group`, `form-control`, `btn btn-primary` |
| JavaScript в браузере | без него остаётся обычное поле без подсказок |

## Установка

1. Скачайте `mod_radicalmart_search_<версия>.zip` из раздела [Releases](../../releases).
2. «Система → Установка → Расширения» → загрузить архив.
3. «Содержимое → Модули сайта → Создать» → «RadicalMart - Поиск товаров».
4. Выберите позицию, назначьте на нужные страницы, опубликуйте.
5. В поле «Пункт меню каталога» укажите страницу каталога (см. ниже, это важно для кнопки поиска).

## Как это работает

1. Посетитель вводит текст. Если длина не меньше «Минимум символов», то после паузы («Задержка») браузер отправляет запрос:

   ```text
   /index.php?option=com_ajax&module=radicalmart_search&method=get&format=json&query=<текст>
   ```

2. Joomla через `com_ajax` вызывает `RadicalMartSearchHelper::getAjax()`. Он подставляет запрос в фильтр `filter[search]` и получает товары штатной моделью `Products` компонента RadicalMart, то есть тем же кодом, который строит каталог. Окно выборки 50 товаров.
3. Из выборки отбираются подходящие по правилам автодополнения (см. ниже), убираются повторы по названию, для каждого собираются ссылка, картинка и цена.
4. Ответ приходит в виде JSON, скрипт рисует список. Клик по подсказке ведёт на страницу товара.

Формат ответа:

```json
{
  "success": true,
  "items": [
    {
      "id": 12,
      "title": "Название товара",
      "link": "https://example.com/catalog/product-12",
      "image": "https://example.com/images/p12.jpg",
      "price": "1990",
      "in_stock": true
    }
  ],
  "total": 1
}
```

Если запрос короче двух символов, приходит `{"success": false, "items": [], "message": "..."}`.

### Что считается совпадением

Штатный текстовый поиск RadicalMart ищет и в описаниях, и в полях, поэтому случайное слово в описании могло бы занять место в десятке подсказок. Модуль отбирает строже:

- **По названию:** каждое слово запроса (от 2 символов) должно встречаться в названии товара. Регистр не важен, `ё` приравнивается к `е`, знаки препинания игнорируются.
- **По артикулу:** весь запрос должен входить в код товара (работает, например, вместе с плагином RadicalMart для поиска по артикулу).
- Товары с одинаковым названием показываются один раз (у товара и его вариантов часто совпадают названия).

### Кнопка и Enter

По кнопке «Найти» или Enter происходит переход на страницу каталога с параметром:

```text
<адрес каталога>?filter[fields][poisk]=<запрос>
```

Адрес каталога берётся из настройки «Пункт меню каталога». Если пункт не выбран, используется корневая категория RadicalMart (или текущая, если вы находитесь в категории).

> **Для страницы результатов нужно поле RadicalMart с алиасом `poisk`.** Фильтр каталога ищет по пользовательскому текстовому полю с алиасом `poisk`. Если такого поля в вашем магазине нет, переход произойдёт, но запрос к выдаче не применится. Создайте текстовое поле с алиасом `poisk` и включите его в фильтр, либо поменяйте имя параметра в `tmpl/default.php`.

## Настройки модуля

| Параметр | По умолчанию | Назначение |
|---|---|---|
| Текст кнопки | Найти | подпись кнопки |
| Placeholder | Поиск товаров... | подсказка в поле |
| Минимум символов | 2 | с какой длины запроса начинать поиск (1–10) |
| Максимум результатов | 10 | см. «Ограничения» ниже |
| Задержка (мс) | 300 | пауза после последней буквы перед запросом (100–2000) |
| Пункт меню каталога | не выбран | куда вести кнопку и Enter |
| Макет | default | стандартный выбор макета, можно подключить свой |
| Суффикс CSS-класса | пусто | добавляется к обёртке `.radicalmart-search-wrapper` |
| Кэширование | выключено | вывод зависит от запроса, кэшировать модуль не нужно |

## Стили и переопределение вёрстки

Стили записаны прямо в `tmpl/default.php`. Основные классы:

| Класс | Что это |
|---|---|
| `.radicalmart-search-wrapper` | обёртка модуля |
| `.search-autocomplete-results` | выпадающий список (`.show` показывает его) |
| `.search-autocomplete-item` | одна подсказка (ссылка) |
| `.search-autocomplete-item-title`, `.search-autocomplete-item-price` | название и цена |
| `.search-autocomplete-loading`, `.search-autocomplete-no-results` | «Поиск...» и «Ничего не найдено» |

Чтобы изменить вид или разметку, скопируйте `tmpl/default.php` в `templates/<шаблон>/html/mod_radicalmart_search/default.php` и правьте копию. Переопределять стили можно и обычным CSS шаблона: они подключены внутри страницы и имеют низкую специфичность.

## Ограничения текущей версии

Версия 1.0.1 написана под конкретные проекты автора, поэтому в ней есть допущения:

- **«Максимум результатов»** сохраняется в настройках, но пока не применяется: показываются все подходящие товары из окна в 50 штук.
- **Валюта** в подсказке всегда «₽», а тексты («Поиск...», «Ничего не найдено», «Ошибка при поиске») вшиты по-русски.
- **Языки:** есть только `ru-RU`.
- **Адрес запроса** начинается с `/index.php`, то есть рассчитан на сайт в корне домена. Для сайта в подпапке или с языковым префиксом адрес нужно поправить в `tmpl/default.php`.
- **Параметр `poisk`** в адресе результатов (см. выше).
- **Стили и скрипт** выводятся прямо в странице для каждого экземпляра модуля.
- Минимальная длина запроса (2 символа) продублирована на сервере и не зависит от настройки.

## Структура

```text
mod_radicalmart_search.xml          манифест
mod_radicalmart_search.php          точка входа, подключает макет
helper.php                          класс ModRadicalmartSearchHelper для com_ajax (вызывает getAjax)
services/provider.php               DI Joomla
src/Dispatcher/Dispatcher.php       данные для макета: адрес каталога, язык RadicalMart
src/Helper/RadicalMartSearchHelper.php   AJAX-поиск и сопоставление
tmpl/default.php                    разметка, стили и скрипт подсказок
language/ru-RU/                     языковые файлы
tools/build.sh                      сборка установочного архива
```

Пространство имён: `Joomla\Module\RadicalMartSearch`.

## Сборка из исходников

```bash
tools/build.sh
```

Архив появится в `dist/`. Пути внутри него записываются через `/` (скрипт сам это проверяет).
